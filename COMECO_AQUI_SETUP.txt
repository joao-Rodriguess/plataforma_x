⚙️ DETALHES TÉCNICOS
═══════════════════════════════════════════════════════════════════════════

CLASSE DatabaseSetup (api/setup.php):
  • generateSecurePassword() - Gera senha aleatória de 20 caracteres
  • generateUsername() - Gera username único
  • createConfigFile() - Cria api/config.php com credenciais
  • createCredentialsFile() - Cria .credentials.txt para backup

CLASSE CreateDatabaseUser (api/create_user.php):
  • connectAsRoot() - Conecta como MySQL root
  • createUser() - Cria usuário no MySQL
  • Executa: CREATE USER / GRANT PRIVILEGES / FLUSH PRIVILEGES

CLASSE InstallDatabase (install_database.php):
  • getCredentials() - Lê credenciais de api/config.php
  • install() - Executa todos os comandos SQL
  • multi_query() - Executa múltiplos comandos SQL

❓ PERGUNTAS FREQUENTES
═══════════════════════════════════════════════════════════════════════════

P: E se eu executar os scripts várias vezes?
R: Cada execução gera novas credenciais. Os arquivos são sobrescritos.

P: Onde meus dados ficam salvos?
R: api/config.php (permanente) e .credentials.txt (temporário)

P: Posso usar as senhas que o script gerou?
R: Sim! Elas são fortes e seguras. Guarde em um password manager.

P: E se perder as credenciais?
R: Acesse mysql como root e altere a senha com:
   ALTER USER 'plat_xxxxx'@'localhost' IDENTIFIED BY 'nova_senha';

P: Qual é o arquivo principal?
R: api/config.php - Este arquivo é usado por toda a aplicação
