🎯 CASOS DE USO MAPEADOS
───────────────────────────────────────────────────────────────────

1. Criar Novo Usuário
   Entrada: Formulário preenchido
   Processo: Validação → Criptografia → INSERT
   Saída: Mensagem de sucesso + Nova lista

2. Listar Usuários
   Entrada: Clique em "Lista"
   Processo: SELECT * → Renderizar tabela
   Saída: Tabela com todos os usuários

3. Editar Usuário
   Entrada: Clique em "Editar"
   Processo: GET usuário → Modal → UPDATE
   Saída: Usuário atualizado + Mensagem

4. Deletar Usuário
   Entrada: Clique em "Deletar"
   Processo: Confirmação → DELETE
   Saída: Usuário removido + Mensagem

5. Validar Dados
   Entrada: Qualquer formulário
   Processo: Validação frontend → backend
   Saída: Mensagem de erro ou sucesso
